Linux · GTK

APT repository

Follow these steps in a terminal on Debian Linux 13 (trixie) to install signet-gtk.

The repository is hosted at apt.signetwallet.org. These instructions use sudo for commands that require administrator privileges.

1. Import the signing key

Install GPG and curl, then add the repository’s signing key to the APT keyring directory.

sudo apt install -y gpg curl
sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL "https://apt.signetwallet.org/keys/signet.asc" | \
    sudo gpg --dearmor -o /etc/apt/keyrings/signet.gpg
sudo chmod 0644 /etc/apt/keyrings/signet.gpg

2. Add the Debian Linux 13 repository

Create the APT source for Debian Linux 13 (trixie):

echo "deb [signed-by=/etc/apt/keyrings/signet.gpg] https://apt.signetwallet.org/debian trixie main" \
    | sudo tee /etc/apt/sources.list.d/signet.list

3. Install Signet

Refresh the package list and install the GTK wallet:

sudo apt update
sudo apt install -y signet-gtk

Once the repository is configured, future package updates are available through APT.
